# Milestone 1 Demo Script

1. Start the Docker stack and open the application.
2. Create `Neuroblastoma Demo`.
3. Upload a multi-sheet CCDI-style workbook or synthetic clinical data.
4. Inspect workbook sheets, row/column counts, and inferred roles.
5. Add `variants.vcf`, `target_sequence.fasta`, and an image to the same cohort.
6. Show that all files remain linked to the same cohort with checksums/provenance.
7. Create a second cohort (e.g. Sarcoma Demo).
8. Create a traceable logical merged cohort.
9. Show downloadable registered files and API documentation.
10. Explain that production semantic mapping, distributed federation, and formal biological validation are staged for Milestones 2 and 3.
