# CCDI Submission Readiness

The application is designed around CCDI Submission Guide concepts:

- preserve study/cohort context;
- support multi-sheet metadata templates;
- retain participant, diagnosis, treatment, survival, sample and file-node relationships;
- support sequencing, radiology/pathology and generic-file metadata;
- maintain comprehensive metadata and provenance;
- use standard file formats;
- support QC before submission;
- use object storage for large scientific files;
- remain open-source and GitHub-deployable.

Future Milestone 2 work will add formal CCDI data-model validation, required-field completeness scoring, controlled vocabulary checks, and submission-package exports.
