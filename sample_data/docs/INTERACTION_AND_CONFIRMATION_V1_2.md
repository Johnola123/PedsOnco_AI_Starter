# Interaction and confirmation update — v1.2

## Drag and drop

The Milestone 1 workspace supports drag-and-drop in contexts where it reduces friction while retaining click/select alternatives:

1. Add Data: drag multiple local files into the upload zone.
2. Cohort Files: drag additional local files directly into the open cohort.
3. Inspect: drop files to upload them into the cohort and inspect the newest item immediately.
4. Integrate: drag existing cohort file cards into Left Source and Right Source slots. Standard selectors remain available for keyboard, touch, and accessibility.

## Confirmation dialogs

Custom confirmation dialogs are shown before:

- removing a saved workspace decision;
- saving edit recipes that drop fields, filter rows, or deduplicate the working view;
- creating an integrated relationship between files;
- creating a cross-cohort merged view.

These confirmations do not imply that raw source files are changed. PedsOnco preserves raw assets and records transformations in the working/provenance layer.
