# Milestone 2 and 3 Roadmap

## Milestone 2 — Detailed project plan (deadline: June 15, 2027)

Planned deliverables:

1. Formal CCDI data-model mapping and validation.
2. Required-field completeness and submission-readiness scoring.
3. Human-reviewed semantic harmonization using aliases, embeddings and ontology/CDE checks.
4. Controlled-vocabulary validation for diagnosis, phenotype, treatment and sample terms.
5. Expanded visualization: demographics, disease state, treatment, survival, missingness, participant-sample relationships and molecular summaries.
6. Statistical/AI analysis modules with leakage-safe validation and explainability.
7. CCDI/C3DC export/import adapters using documented interfaces and approved access paths.
8. Pilot privacy-preserving federation using the separate PedsOnco Federation Expansion repository.
9. Data-quality evaluation plan, risk register, documentation, testing and communication plan.
10. Legal/data-use/Institutional Certification activities completed where applicable.

Milestone 2 evidence:

- architecture and data-flow diagrams;
- test datasets and reproducible demonstrations;
- mapping accuracy/QC metrics;
- preliminary biological/analysis results where possible;
- Docker/GitHub release candidate;
- detailed timeline and deliverables through Milestone 3.

## Milestone 3 — Project completion (deadline: December 14, 2029)

Planned outcomes:

1. Production-ready CCDI-compatible ingestion/harmonization workflows.
2. Validated multimodal cohort integration across multiple pediatric/AYA cancer studies.
3. Federated or privacy-preserving multi-site analysis demonstration where governance permits.
4. Complete data-quality assessment and reproducibility/provenance reports.
5. AI/ML and/or statistical analyses yielding scientifically interpretable outputs.
6. Delivery of applicable tools, source code, documentation and permitted primary/derived datasets to CCDI/GitHub.
7. At least one clear reuse example by an external or independent research workflow.
8. Evidence of scientific impact such as analysis results, manuscript/publication, new collaboration/study, reusable software metrics, or other challenge-recognized outcomes.

## Phase II readiness

The Milestone 3 system should be packaged for cross-platform validation and broader implementation, with deployment documentation, governance controls, reproducibility tests and site onboarding materials.
