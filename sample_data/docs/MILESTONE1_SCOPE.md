# Milestone 1 Scope

## Submission positioning

**Primary recommendation:** Track 2 — leverage CCDI resources to advance biological insight through interoperable multimodal cohort preparation, harmonization, integration, and analysis-readiness.

Milestone 1 is a proposal-stage competition. The software in this repository is preliminary feasibility evidence, not a claim that every Milestone 2/3 capability is already production-ready.

## Scientific question

Can a reusable, human-reviewed data harmonization and cohort-integration workflow make heterogeneous pediatric and AYA cancer datasets easier to discover, inspect, standardize, combine, and prepare for downstream AI/ML and biological analyses while preserving source provenance?

## Milestone 1 deliverable demonstrated here

1. Multimodal cohort container.
2. Multi-sheet CCDI-style workbook inspection.
3. Large-object registration via MinIO/S3.
4. External URL/API ingestion.
5. Cohort-aware provenance.
6. Logical cohort merging.
7. Responsive exploration UI.
8. Open-source Docker deployment.

## Intentionally deferred

- Production federated learning across institutions.
- Site authentication and mTLS.
- Secure aggregation/differential privacy.
- Production ontology services and caDSR/controlled-vocabulary APIs.
- Production-scale model validation.
- Institutional data-use agreements and governance workflows.

These are Milestone 2/3 activities and are prototyped separately in the federation expansion repository.
